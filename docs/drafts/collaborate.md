# 合作开发

如果你有意愿和我共同开发上架游戏或制作教程，欢迎和我联系。目前有三种合作方式：

## 我参与辅助

由你（们）主导的项目，我不干涉任何内容或创意，主要承担的工作是定期制作 devlog 帮你宣传，以及核心算法攻关（若有需要）。这项合作对我来说是为了积累游戏开发经验，因此我不参与分成，也不要求你有游戏开发经验，只要你的策划案我认可即可。限时 offer。

## 我主导的项目

我自己最想做的游戏类型：**剧情丰富**、**高自由度**、**奇幻风格**的 **2D JRPG** 游戏，如果你也对开发这类游戏有热情，欢迎加入（擅长程序、美术、关卡设计、剧本设计等均可）。项目尚在筹划中，细节可共同讨论，但**要求你有游戏开发/剧本撰写经验**。

## 教学视频项目

如果你擅长剪视频，且能够制作**概念演示型动画**（常见于技术或科普博主），欢迎合作，兼职全职皆可。
