## 🎮 课程简介

欢迎来到 C++ 游戏开发之旅的第五期课程：《迷你农场》（TinyFarm）。

在上一期课程的基础上，本期我们将引入三个关键能力：**OpenGL 图形渲染**、**FreeType/HarfBuzz 字体排版**、**MiniAudio 音频播放**，并在此之上构建一个更大规模、更完整的项目：**迷你农场（TinyFarm）**。

相比前几期课程，本期课程是一次**重大进阶**。这不仅仅因为代码量已经超过4万行，更因为我们开始真正对标**专业游戏项目**的标准：
- 渲染层采用经典的 **SDL + OpenGL** 组合；
- 文本处理引入 **FreeType + HarfBuzz** 工业级方案；
- 音频管理交由 **MiniAudio** 负责。

这些基础设施的选择，旨在让你接触到与主流商业引擎保持一致的技术栈与开发流程。

## 🚨 全新的学习模式

正因为项目规模的增长，从本期课程开始，我们的学习方式将发生两个重大变化：

1. **不再逐行讲解代码**：我们将把重点放在**各个功能的原理**以及**代码的设计思路**上。具体的实现细节，请大家对照每节课的文件清单，直接阅读开源仓库中的源码。
2. **基于完整工程剖析**：代码不再按课节内容“渐进式”给出，而是直接提供一个**完整的、可运行的项目**。我们将像拆解精密仪器一样，从入口开始，逐层剥开这个庞大系统的外壳。

**为什么这么做？**
因为这才是真实游戏开发的工作常态。在工作中，你很少有机会从零写一个引擎，更多时候，你需要快速理解现有的代码库，并在此基础上进行维护或扩展。

## 🌾 项目预览：迷你农场 (TinyFarm)

TinyFarm 是一个功能完备的 2D 农场经营教学 Demo。它虽然是一个教学项目，但“麻雀虽小，五脏俱全”：

### ✨ 核心特性

- 🎮 **完整的农场玩法**：种植、浇水、收获、交互、物品管理
- 🗺️ **多地图与世界管理**：地图切换、预加载、快照与离线推进
- 🎨 **精美的 2D 渲染**：光照、后处理、像素风渲染要点
- 🖼️ **完整的 UI 系统**：物品栏、快捷栏、对话、菜单
- 🎵 **音频系统**：音效与背景音乐、2D 空间声
- 🌅 **昼夜循环**：时间系统驱动的环境变化
- 💾 **存档功能**：游戏状态的保存与读取

## 📚 本期课程你将收获什么？

我们将通过 **32 节课** 的内容，带你深入以下五个核心领域：

1. **OpenGL 实战应用**：不仅仅是画三角形，而是实现一套简洁实用的 2D 光照系统与批处理渲染流。
2. **字体与音频工程化**：学习如何处理复杂的字形排版、字体缓存，以及 2D 空间音频的播放与管理。
3. **空间与地图管理**：掌握进阶的瓦片地图处理、自动图块（Auto-tiling）、地图快照以及双层网格空间分区技术。
4. **游戏系统架构**：深入理解 ECS 在实际项目中的应用，以及事件驱动、UI 框架与数据加载流程的配合。
5. **完整玩法闭环**：亲手从零梳理种植、收获、昼夜交替等逻辑，理解数据是如何在这些系统间流转的。

## 📋 前置知识与建议

本课程可以看作是一个全新的起点，前四期内容**并非必须**，但你需要具备以下基础：

- **C++ 基础**：熟悉现代 C++ 的常用特性，能够独立阅读和理解中等复杂度的 C++ 代码。
- **游戏开发基础**：理解游戏循环、事件、更新、渲染等概念，至少完成过一个简单的游戏项目。
- **关于 OpenGL**：
    - **如果你是初学者**：可以略过 OpenGL 的底层实现细节，直接使用项目封装好的接口（把它当成加强版的 SDL_Renderer）。
    - **如果你想深入**：建议先学习 [LearnOpenGL](https://learnopengl.com/) 的前两章内容，掌握基本的图形学概念。
