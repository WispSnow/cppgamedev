# 网站页面设计优化清单

> 基于 2026-02-22 的全站设计评估，按优先级排列

## 高优先级

- [x] **1. 课程卡片图片统一比例 + 描述截断** (2026-02-22 已完成)
  - 统一课程卡片图片为 16:9 比例，使用 `aspect-ratio: 16/9` + `object-fit: cover`
  - 限制描述文字为 3 行 + 省略号 (`-webkit-line-clamp: 3`)，保证卡片高度一致
  - 给图片区域加渐变遮罩，难度标签叠在图片左上角
  - hover 时图片有 `scale(1.05)` 微缩放效果
  - 修改涉及: HomePage.tsx, MainlinePage.tsx, SideQuestsPage.tsx, CoursesPage.tsx

- [x] **2. 章节列表改为紧凑形式** (2026-02-22 已完成)
  - 从 2 列大卡片网格改为单列紧凑列表，包裹在圆角卡片容器中
  - 每行：编号圆圈 + 标题 + 单行描述（溢出截断）+ 右箭头
  - 基于 localStorage 阅读历史显示绿色"已读"标签
  - 标题处显示总章节数（如"课程章节 (33)"）
  - 修改涉及: CourseDetailPage.tsx

- [x] **3. 阅读页正文最大宽度限制** (2026-02-22 已完成)
  - MarkdownContainer 添加 `max-width: 720px; margin: 0 auto`
  - 行高从 1.8 微调到 1.85，段落间距 1.25rem
  - h1/h2/h3 各级标题差异化间距和字号，h2 带底部分隔线
  - blockquote 增加淡蓝背景、圆角和更好的内边距
  - li 增加 0.35rem 间距，列表更易读
  - 修改涉及: CoursePartPage.tsx
